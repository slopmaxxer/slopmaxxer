### things i build & maintain
- **[slopbgp](https://github.com/slopmaxxer/slopbgp)** — autonomous BGP-4 & MP-BGP routing daemon in Gleam on Erlang/OTP BEAM for DN42
- **[slop-landing](https://github.com/slopmaxxer/slop-landing)** — official landing page and slime engine for [freifick.net](https://freifick.net)
- **[lantern](https://github.com/slopmaxxer/lantern)** — experimental webserver in Haskell with Caddy-style config, HTTP/1, TLS 1.3, and ACME
  - **[lantern-tls](https://github.com/slopmaxxer/lantern-tls)** — clean-room TLS 1.3 protocol library in Haskell
  - **[lantern-http](https://github.com/slopmaxxer/lantern-http)** — strict HTTP/1 wire protocol library in Haskell
- **[trough](https://github.com/slopmaxxer/trough)** — lightweight ActivityPub server in Go + SQLite with web UI and Mastodon client API support
- **[slopbox](https://github.com/slopmaxxer/mayfly)** — ephemeral file host written in Gleam on Erlang/OTP
- **[open-grind-ios](https://github.com/slopmaxxer/open-grind-ios)** — native SwiftUI iOS port of Open Grind, the open source Grindr client, with a Rust transport via UniFFI
- **[xy-remote](https://github.com/slopmaxxer/xy-remote)** — SwiftUI iOS remote and reverse engineered Bluetooth LE protocol library for XinYi (Sinilink) amplifier boards
- **[hydra](https://github.com/slopmaxxer/hydra)** — soft fork of Lix's Hydra (Nix CI) with live build status and streaming logs
- **[hydra-mcp](https://github.com/slopmaxxer/hydra-mcp)** — MCP server for Hydra: jobsets, evaluations, builds, logs and the queue
- **[driftline](https://github.com/slopmaxxer/driftline)** — static OpenAPI schema difference and migration analyzer
- **[therapie-mcp](https://github.com/slopmaxxer/therapie-mcp)** — Python Model Context Protocol server for directory search and enquiry workflow
- **[arbeitsagentur-mcp](https://github.com/slopmaxxer/arbeitsagentur-mcp)** — MCP server for German employment agency APIs and deadlines
- **[dn42](https://github.com/slopmaxxer/dn42)** — DN42 BGP routing and WireGuard peering infrastructure (`AS4242420125`)
- **[server-backups](https://github.com/slopmaxxer/server-backups)** — verified daily SQLite and upload backup pipeline
- **[nixfiles](https://github.com/slopmaxxer/nixfiles)** — declarative NixOS configuration for the freifick.net server
